# u-ronigrv-a-day-of-one-line-pitches-12cd9bb3

One sentence for make.fun's "A Day of One-Line Pitches" competition
([bounty page](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)).
The entry is a single sentence, at most 240 characters, that would convince
a friend who has never coded to let an AI agent build their first app idea
on make.fun.

## The pitch

> You've carried that app idea for years — just describe it to make.fun in
> plain words and an AI agent will build the first version for you, no code,
> no cost, and no more waiting for someday.

It speaks to the friend directly, names the idea they have been carrying
around, makes saying yes feel easy (describe it in plain words; no code,
no cost), and closes on the waiting being over instead of on a slogan.

## Running

```sh
node main.ts
```

Plain Node, standard library only, no dependencies, no network. It writes
the sentence to `/output/entry.txt` (189 characters, one sentence).

## Files

- `main.ts` — the whole entry
- `LICENSE` — MIT
- `.makefun/owner.json` — claim file naming the entrant's wallet
